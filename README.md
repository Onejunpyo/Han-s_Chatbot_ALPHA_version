# ✦ 데이터 도우미 — 말로 쓰는 회귀·신경망 챗봇

Gemini처럼 **말로 물어보면** 선형 회귀, 비선형 회귀, 인공신경망을 실행해 주는 챗봇입니다.
대화는 **OpenAI(LLM)**가 이해하고, Notion과 GitHub에 직접 연결되어 페이지와 파일을 읽고 쓸 수 있습니다.
**PDF·Word·엑셀·CSV·이미지 파일**을 올릴 수 있고, **이전 대화와 사용자 정보를 기억**하며, **한국어와 English**를 모두 지원합니다.

> 동아대학교 조선해양공학과 데이터처리개론 과제

## 🗣️ 이렇게 말하면 됩니다

| 하고 싶은 일 | 한국어 | English |

## 📎 파일 첨부

입력창 왼쪽의 📎 버튼을 누르거나, 파일을 화면에 **끌어다 놓거나**, 입력창에 **붙여 넣으면** 첨부됩니다. (한 번에 8개, 파일 하나 20MB까지)

| 파일 | 챗봇이 하는 일 |
|---|---|
| **CSV, 엑셀(.xlsx)** | 열마다 평균·표준편차·최소·최대·합계와 상관계수를 계산하고, 첫 두 숫자 열을 x, y로 준비합니다. |
| **PDF, Word(.docx), 텍스트** | 글자를 뽑아 자주 나오는 단어와 핵심 문장을 보여 주고, 내용에 대한 질문에 답합니다. |
| **이미지, 스캔한 PDF** | AI 모드에서 그림을 보고 설명합니다. |

### 💬 파일에 대해 질문하기

파일을 올린 뒤 그냥 물어보면 됩니다. 한 번 올린 파일은 그 대화가 끝날 때까지 기억합니다.

| 하고 싶은 일 | 한국어 | English |
|---|---|---|
| 요약 | `이 파일 요약해줘`, `핵심만 정리해줘` | `summarize this file` |
| 내용 질문 | `결론이 뭐야?`, `XOR 문제는 왜 은닉층이 필요해?` | `what was the maximum resistance?` |
| 표 통계 | `평균이 얼마야?`, `resistance 최댓값 알려줘` | `what is the average?` |
| 파일 고르기 | `report.pdf에서 실험 방법 찾아줘` | `in report.pdf, what was the method?` |
| 분석 | `가장 잘 맞는 모델 찾아줘` (표 파일) | `find the best model` |

**어떻게 답을 찾나요?**

| 방식 | 답하는 방법 |
|---|---|
| **기본 모드** (인터넷 없이도 됨) | 파일을 작은 조각으로 나눈 뒤, 질문 단어와 가장 많이 겹치는 조각을 **BM25 점수**로 찾습니다. 그 조각에서 가장 관련 있는 문장을 **출처(파일 이름과 쪽 번호)**와 함께 보여 줍니다. 한국어는 조사(은, 는, 을, 를…)를 떼고 비교합니다. |
| **✦ AI 모드** | 위와 같은 방법으로 찾은 부분을 OpenAI에게 함께 보내고, AI가 내용을 이해해서 자연스러운 문장으로 답합니다. 답에는 `(report.pdf, p. 2)`처럼 출처를 붙이고, 파일에 없는 내용은 지어내지 않고 "없다"고 답하도록 했습니다. 긴 파일은 필요한 부분을 AI가 직접 찾아 읽습니다. |

- 파일은 **브라우저 안에서** 읽습니다. 따로 서버에 저장하지 않고, AI 모드일 때만 필요한 내용이 OpenAI로 전달됩니다.
- 기본 모드는 문장을 **찾아서 보여 주는** 방식이라, 여러 문장을 종합해야 하는 질문은 AI 모드가 더 정확합니다.

---|---|
| **CSV, 엑셀(.xlsx)** | 숫자 열을 찾아 첫 두 열을 x, y로 준비합니다. 바로 `가장 잘 맞는 모델 찾아줘`라고 하면 됩니다. |
| **PDF, Word(.docx), 텍스트** | 글자를 뽑아 냅니다. AI 모드에서는 요약하고 내용에 대해 질문에 답합니다. 글 속 숫자로 회귀 분석도 할 수 있습니다. |
| **이미지, 스캔한 PDF** | AI 모드에서 그림을 보고 설명합니다. (그래프 사진 속 값을 읽어 분석하는 것도 가능합니다) |

- 파일은 **브라우저 안에서** 읽습니다. 따로 서버에 저장하지 않고, AI 모드일 때만 글자 내용이 OpenAI로 전달됩니다.
- 기본 모드에서는 파일 앞부분과 숫자 표만 다룹니다. 요약·질문은 AI 모드에서 할 수 있습니다.

## 🔎 인터넷 검색

인터넷에 연결되어 있으면, **정해진 표현이 아닌 질문도** 인터넷에서 찾아 답합니다.

| 이렇게 물으면 | 챗봇이 하는 일 |
|---|---|
| `인터넷에서 부력 검색해줘`, `search the web for buoyancy` | 바로 인터넷에서 찾습니다. |
| `베르누이 정리가 뭐야?`처럼 챗봇이 정해 둔 표현이 아닌 질문 | 알아듣지 못했다고 하지 않고 인터넷에서 찾아 답합니다. |
| 파일을 올렸는데 파일에 없는 내용을 물을 때 | "파일에서는 찾지 못했다"고 알려 준 뒤 인터넷에서 찾습니다. |

검색은 **중계 서버(Cloudflare Worker)**가 대신 해 줍니다. 아래 순서로 시도하고, 앞 단계가 안 되면 자동으로 다음 단계로 넘어갑니다.

| 순서 | 검색 방법 | 검색 범위 | 필요한 것 |
|---|---|---|---|
| ① | **OpenAI 웹 검색** | 인터넷 전체, AI가 결과를 종합해 답함 | `OPENAI_API_KEY` (유료) |
| ② | **인터넷 전체 검색** | 인터넷 전체 (뉴스, 블로그, 공식 사이트 등) | **아무 키도 필요 없음** (DuckDuckGo 사용). `TAVILY_API_KEY`를 넣으면 더 안정적 |
| ③ | 위키백과 (브라우저에서 바로) | 위키백과 | 없음 |
| ④ | 위키백과 (중계 서버 경유) | 위키백과 | 없음 |

**OpenAI 키가 없어도 중계 서버만 있으면 ②번으로 인터넷 전체를 검색합니다.**
- 검색 결과 위쪽 3개 사이트의 본문을 읽어 와서, 질문과 가장 관련 있는 문장을 찾아 **출처 링크와 함께** 보여 줍니다. (파일 질문과 같은 방법)
- AI 모드에서는 그 내용을 AI가 읽고 종합해서 답합니다.

### (선택) 더 안정적으로 검색하기 — Tavily 무료 키

키 없이 쓰는 DuckDuckGo 검색은 너무 자주 쓰면 잠시 막힐 수 있습니다. 그럴 때는 무료 검색 키를 넣으십시오.

1. https://tavily.com 에 가입합니다. (카드 등록 없음, **한 달 1,000번 무료**)
2. 대시보드에서 API 키(`tvly-...`)를 복사합니다.
3. Cloudflare Worker의 **Settings → Variables and Secrets**에 `TAVILY_API_KEY`를 **Secret**으로 넣습니다.

### 알아 두기

- 검색 결과는 카드로 보여 주며, 각 출처를 눌러 원문을 확인할 수 있습니다.
- **설정 및 기억 → 인터넷 검색 확인** 버튼으로 각 검색 방법이 되는지 한 번에 확인할 수 있습니다.
- **설정 및 기억 → 대화 방식 → 인터넷 검색 사용**에서 끌 수 있습니다.
- OpenAI 웹 검색은 일반 대화보다 요금이 조금 더 나옵니다. 중계 서버의 `WEB_SEARCH`에 `off`를 넣으면 OpenAI 검색만 끄고 ②~④는 계속 씁니다.

## 🧩 어떻게 만들어져 있나요?

```
 ┌──────────────────────┐        ┌────────────────────────────┐        ┌──────────┐
 │  챗봇 화면            │        │  중계 서버                  │ ─────▶ │  OpenAI  │
 │  index.html          │ ─────▶ │  worker.js                 │ ─────▶ │  Notion  │
 │  (GitHub Pages)      │ ◀───── │  (Cloudflare Worker, 무료)  │ ─────▶ │  GitHub  │
 │                      │        │  토큰과 API 키는 여기에만    │        └──────────┘
 │  회귀·신경망 계산과    │        └────────────────────────────┘
 │  파일 읽기는 브라우저   │
 └──────────────────────┘
```

| 부분 | 하는 일 |
|---|---|
| **index.html** | 채팅 화면, 회귀·신경망 계산, 그래프, 파일 읽기, 대화 기록과 기억 저장, 한국어/English |
| **worker.js** | OpenAI·Notion·GitHub와 대신 통신하는 작은 서버 |

**왜 중계 서버가 필요합니까?**
- API 키와 토큰을 `index.html`에 적으면 누구나 볼 수 있습니다. 중계 서버에 넣어 두면 밖으로 드러나지 않습니다.
- Notion은 보안 정책상 웹 페이지에서 직접 접속하는 것을 막아 두었습니다.

**두 가지 대화 방식이 있습니다.**

| 방식 | 언제 | 특징 |
|---|---|---|
| ✦ **AI 모드** | 중계 서버에 OpenAI API 키가 있을 때 | 자유롭게 대화합니다. OpenAI 모델이 상황에 맞는 도구(회귀, 신경망, 파일, Notion, GitHub, 기억)를 스스로 골라 씁니다. |
| **기본 모드** | 중계 서버가 없거나 OpenAI가 응답하지 않을 때 | 위 표처럼 정해진 표현을 알아듣습니다. 회귀·신경망 계산은 인터넷 없이도 됩니다. |

어느 모드든 **계산은 브라우저에서 직접** 합니다. AI가 숫자를 지어내지 않도록, 계산은 반드시 도구로 하게 되어 있습니다.

## 🚀 1단계 · 챗봇 화면 올리기 (이것만 해도 기본 모드로 동작합니다)

1. GitHub에서 **새 저장소**를 만듭니다. (예: `data-helper`, Public)
2. `index.html`을 저장소 **맨 바깥(최상단)**에 올립니다.
3. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/data-helper/`로 접속합니다.

이 상태에서도 회귀 분석, 신경망 학습, 파일 읽기, 기억 기능은 모두 동작합니다. AI 대화와 Notion·GitHub 연결을 쓰려면 아래 단계를 이어서 하십시오.

## 🔑 2단계 · 열쇠 세 개 준비하기

필요한 것만 준비하면 됩니다. 없는 기능은 꺼진 채로 나머지가 동작합니다.

### ① OpenAI API 키 (AI 대화용)

1. https://platform.openai.com/api-keys 에 로그인합니다.
2. **Create new secret key**를 눌러 키를 만들고 복사해 둡니다. (다시 볼 수 없으니 바로 복사하십시오)
3. ⚠️ OpenAI API는 **사용한 만큼 요금이 나옵니다.** **Settings → Billing**에서 결제 수단을 등록하고 크레딧을 충전해야 동작합니다. **Limits**에서 월 사용 한도를 정해 두면 안심입니다.
4. 기본 모델은 빠르고 저렴한 `gpt-5.4-mini`입니다. 다른 모델을 쓰려면 3단계에서 `OPENAI_MODEL`을 넣습니다.

### ② Notion 통합 시크릿 (Notion 읽고 쓰기용)

1. https://www.notion.so/profile/integrations 에서 **새 통합(New integration)**을 만듭니다.
   - 이름: `데이터 도우미`, 유형: **내부(Internal)**
2. 만든 통합에서 **내부 통합 시크릿(Internal Integration Secret)**을 복사해 둡니다.
3. ⚠️ **꼭 해야 하는 일:** 챗봇이 볼 Notion 페이지를 열고, 오른쪽 위 **⋯ → 연결(Connections)**에서 `데이터 도우미` 통합을 추가합니다.
   - 연결한 페이지와 그 **하위 페이지**만 챗봇이 볼 수 있습니다.
   - 챗봇이 새 페이지를 만들면 이 페이지 아래에 만들어집니다.
4. 그 페이지의 주소를 복사해 둡니다. (`NOTION_PARENT_PAGE_ID`에 넣습니다)

### ③ GitHub 토큰 (GitHub 파일 읽고 쓰기용)

1. GitHub 오른쪽 위 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. **Repository access**에서 **Only select repositories**를 고르고 데이터를 둘 저장소(예: `2229455-`)를 선택합니다.
3. **Permissions → Repository permissions → Contents**를 **Read and write**로 바꿉니다.
4. **Generate token**을 누르고 토큰을 복사해 둡니다.

## ☁️ 3단계 · 중계 서버 만들기 (Cloudflare Worker, 무료)

1. https://dash.cloudflare.com 에 가입하고 로그인합니다.
2. 왼쪽 메뉴의 **Workers & Pages**에서 **Create → Worker**를 누르고, 기본 예제(Hello World)를 고릅니다.
3. 이름을 `data-helper`로 정하고 **Deploy**를 누릅니다.
4. **Edit code**를 눌러 기존 코드를 모두 지우고 `worker.js` 내용을 붙여 넣은 뒤 **Deploy**를 누릅니다.
5. Worker의 **Settings → Variables and Secrets**에서 아래 값을 추가합니다. 열쇠는 **Secret**, 나머지는 **Text**로 넣습니다.

| 이름 | 종류 | 넣을 값 | 예시 |
|---|---|---|---|
| `OPENAI_API_KEY` | Secret | ①에서 만든 키 | `sk-...` |
| `NOTION_TOKEN` | Secret | ②의 통합 시크릿 | |
| `NOTION_PARENT_PAGE_ID` | Text | ②에서 연결한 페이지 주소 | `https://app.notion.com/p/3f5c...` |
| `GITHUB_TOKEN` | Secret | ③의 토큰 | |
| `GITHUB_REPO` | Text | `아이디/저장소이름` | `Onejunpyo/2229455-` |
| `ALLOWED_ORIGIN` | Text | 챗봇 사이트의 **도메인만** | `https://onejunpyo.github.io` |

## 🔗 4단계 · 챗봇과 중계 서버 연결하기

**방법 A (추천):** `index.html`에서 아래 줄을 찾아 Worker 주소를 넣고 GitHub에 다시 올립니다. 어느 기기에서 열어도 바로 연결됩니다.

```js
const CONFIG = { WORKER_URL: "https://hanchatbot.2229455.workers.dev" };  // ← 지금 이 주소가 들어가 있습니다
```

**방법 B:** 챗봇 왼쪽 아래 **설정 및 기억**에서 Worker 주소를 입력하고 **연결 확인**을 누릅니다. (그 브라우저에만 저장됩니다)

`ACCESS_CODE`를 정했다면 **설정 및 기억**에 접근 코드를 입력합니다. 접근 코드는 코드에 적지 않고 각 브라우저에 따로 저장되므로, 사이트 주소를 아는 다른 사람이 내 OpenAI 크레딧이나 Notion·GitHub를 마음대로 쓸 수 없습니다.

연결되면 위쪽에 **✦ AI 모드**가 표시되고, 왼쪽 아래 점 세 개(OpenAI·Notion·GitHub)가 초록색으로 바뀝니다.

## 🧠 기억 기능

| 무엇을 | 어떻게 | 어디에 저장 |
|---|---|---|
| **대화 기록** | 왼쪽 목록에서 예전 대화를 눌러 이어서 대화합니다. 그래프도 다시 그려집니다. | 브라우저 |
| **사용자 정보** | "내 이름은 ○○야", "기억해 줘: ○○"라고 말하면 저장하고, 새 대화에서도 사용합니다. | 브라우저 |
| **대화 속 데이터와 파일** | 한 번 입력한 데이터나 올린 파일은 "x가 10일 때 예측해줘", "2차로 다시 해줘"처럼 이어서 씁니다. | 대화 기록 안 |

- AI 모드에서는 이전 대화 내용과 기억한 내용을 OpenAI에게 함께 보내므로, "지난번에 했던 데이터로 다시 해줘" 같은 말도 알아듣습니다.
- **설정 및 기억 → 다른 기기와 이어 쓰기**를 켜면, 대화 기록과 기억이 GitHub 저장소의 `chatbot-data/history.json`에 저장되어 다른 기기에서도 이어 쓸 수 있습니다.
- 이미지는 저장 공간을 아끼기 위해 대화 기록에 저장하지 않습니다.

## 🛡️ 보안 주의

- API 키와 토큰은 **절대 `index.html`에 적지 마십시오.** 반드시 Cloudflare Worker의 **Secret**에만 넣습니다.
- `ALLOWED_ORIGIN`과 `ACCESS_CODE`를 꼭 설정하십시오. OpenAI는 사용한 만큼 요금이 나오므로 특히 중요합니다.
- 사용할 OpenAI 모델은 중계 서버에서만 정합니다. 화면에서 다른 모델로 바꿔 요청할 수 없습니다.
- 챗봇이 Notion이나 GitHub에 **쓰기** 전에는 화면에 **허용 / 취소** 버튼이 나옵니다. 허용을 눌러야만 저장됩니다.
- 개인정보가 들어 있는 파일은 AI 모드에서 OpenAI로 전달된다는 점을 기억하십시오.

## 🔧 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 위쪽에 계속 "기본 모드"라고 나옵니다 | 설정에서 **연결 확인**을 눌러 보십시오. Worker의 `OPENAI_API_KEY`가 있는지 확인하십시오. |
| "OpenAI 계정의 크레딧이 부족합니다" | platform.openai.com **Billing**에서 크레딧을 충전하십시오. 그동안은 기본 모드로 자동 전환되어 답합니다. |
| "OpenAI API 키가 올바르지 않습니다" | 키를 다시 만들어 `OPENAI_API_KEY`에 넣으십시오. 앞뒤 공백이 없어야 합니다. |
| 모델을 쓸 수 없다는 오류 | Worker의 `OPENAI_MODEL`에 platform.openai.com 의 Models 목록에 있는 이름을 넣으십시오. |
| "허용되지 않은 주소에서 온 요청" | `ALLOWED_ORIGIN`이 챗봇 사이트 도메인과 같은지 확인하십시오. 경로 없이 `https://아이디.github.io`만 적습니다. |
| "접근 코드가 맞지 않습니다" | 설정의 접근 코드가 Worker의 `ACCESS_CODE`와 같은지 확인하십시오. |
| Notion 페이지를 찾을 수 없습니다 | 그 페이지의 **⋯ → 연결**에 `데이터 도우미` 통합을 추가했는지 확인하십시오. |
| GitHub 권한이 부족합니다 | 토큰의 **Contents** 권한이 **Read and write**인지, 저장소가 선택되어 있는지 확인하십시오. |
| PDF·Word·엑셀이 "읽지 못함"으로 나옵니다 | 이 형식은 처음 한 번 인터넷에서 읽기 도구를 불러옵니다. 인터넷 연결을 확인하십시오. 암호가 걸린 파일은 읽을 수 없습니다. |
| "인터넷 검색을 하지 못했습니다" / "접속이 막혔습니다" | **설정 및 기억 → 인터넷 검색 확인**을 눌러 어느 단계가 막혔는지 보십시오. 학교·회사 와이파이나 광고 차단 프로그램이 위키백과를 막는 경우가 많습니다. 중계 서버(worker.js 새 버전)를 연결하면 막힌 경우에도 중계 서버를 거쳐 검색합니다. |
| 인터넷 검색이 위키백과로만 됩니다 | Worker를 **새 worker.js**로 바꿨는지 확인하십시오. `/health`에 `"web":true`가 보여야 합니다. |
| "DuckDuckGo가 자동 검색을 잠시 막았습니다" | 잠시 뒤에 다시 하거나, Worker에 무료 `TAVILY_API_KEY`를 넣으십시오. |
| 🎤 버튼이 안 보입니다 | 음성 인식은 Chrome·Edge·Safari에서 됩니다. Firefox는 지원하지 않습니다. |
